# ديمو «قارئ الفواتير الذكي» على الـ homelab

نسخة عرض عامة من مشروع `blind_invoice_mvp`: رفع فاتورة ← استخراج البيانات ← قيد SCF متوازن ← تحقق من NIF وRC وArticle وNIS ← تنبيهات جبائية ← تصدير Excel وPC Compta.

- **لا قاعدة بيانات ولا تخزين:** لا يُحفظ أي ملف أو نتيجة، فلا يرى زائر فواتير غيره.
- **خفيف:** لا Streamlit ولا pandas ولا numpy (تجنباً لتعليمات لا يدعمها معالج Core 2 Duo)، وحد الذاكرة 200MB.
- **الحماية:** حد للتحليلات لكل IP، وسقف يومي عام، وفحص نوع الملف من محتواه، وحد للحجم وعدد صفحات PDF.

---

## 1) انقل المجلد

من اللابتوب، في مجلد التنزيلات:
```bash
scp invoice-demo.zip homelab:~/
```
ثم بعد `ssh homelab`:
```bash
cd ~ && unzip -o invoice-demo.zip && cd invoice-demo
```

## 2) الإعدادات

```bash
cp .env.example .env
grep '^GEMINI_API_KEY=' ~/rag-demo/.env    # لنسخ نفس مفتاح ديمو RAG
nano .env
chmod 600 .env
```
ضع المفتاح في `GEMINI_API_KEY`. الديموهان يتقاسمان نفس الحصة اليومية، فاجعل مجموع `DAILY_EXTRACT_CAP` هنا
و`DAILY_QUESTION_CAP` في ديمو RAG أقل من حد الطلبات اليومي الظاهر في AI Studio.

## 3) التشغيل

```bash
docker compose up -d --build
sleep 10
docker logs --tail 5 invoice_demo
curl -s http://127.0.0.1:8020/health
```
يجب أن ترى `{"ok":true}`.

لتجربته بخصوصية قبل نشره، افتح طرفية جديدة على اللابتوب:
```bash
ssh -L 8020:127.0.0.1:8020 homelab
```
ثم افتح في المتصفح: `http://localhost:8020/invoices` واضغط «جرّب بفاتورة نموذجية».

## 4) النشر على المسار /invoices

ديمو RAG يبقى على الرابط الرئيسي، وقارئ الفواتير يُضاف على مسار فرعي:
```bash
sudo tailscale funnel --bg --set-path /invoices http://127.0.0.1:8020
tailscale funnel status
```
الرابط العام: `https://abdelhmid-vostro-1015.tailc599d9.ts.net/invoices`

للإيقاف: `sudo tailscale funnel --set-path /invoices off`

## 5) للمعرض

- صوّر فيديو: «جرّب بفاتورة نموذجية»، ثم النتيجة، ثم تنزيل Excel وفتحه.
- اذكر أن النسخة الكاملة فيها أرشيف وصندوق مراجعة ومستشار مالي ولوحة مؤشرات، واعرضها بالفيديو.

## ملاحظات

- الفاتورة النموذجية وهمية بالكامل وعليها علامة «SPÉCIMEN – FICTIF».
- التحقق من المعرفات الجبائية يخص **الصيغة** فقط، لا تسجيلها لدى الإدارة الجبائية.
- عتبات الدفع النقدي: 300,000 دج (TTC) لخصم الأعباء (المادة 169 من قانون الضرائب المباشرة، قانون المالية 2018)،
  و100,000 دج لخصم الرسم على القيمة المضافة (المادة 30 من قانون الرسوم على رقم الأعمال). العبارات استرشادية وتحث على مراجعة آخر قانون مالية.
